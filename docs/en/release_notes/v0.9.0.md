## Minimal UI

A cleaner Home and Settings experience without hiding P2 power features.

### Connect in ≤2 taps

1. On **Home**, tap the **profile quick-picker** to choose an active profile (name and type only — no config links or secrets).
2. Tap **Connect**.

When a profile is already selected, connect is **one tap**. Favorites appear first in the picker sheet.

### Slim Settings

**Settings** keeps essentials: Appearance (theme + language), core engine, work mode, diagnostics, and RioNexGate panel. Kill switch, DNS, routing, censorship, certificate pinning, and split tunneling moved to **Advanced**.

### Advanced settings screen

**Settings → Advanced** opens a dedicated screen with all P2 security and routing cards unchanged in behavior:

- Kill switch
- Advanced DNS (mobile TUN)
- Custom routing rules
- Censorship resistance
- Subscription certificate pinning
- Split tunneling (Android VPN)

System theme (`ThemeMode.system`) remains the default.

## Full localization (RU/EN)

The main app UI is fully localized via `flutter gen-l10n`.

### Language setting

**Settings → Appearance → Language**

| Option | Behavior |
|--------|----------|
| **System** | Follow OS locale (RU or EN when supported) |
| **English** | Force English |
| **Русский** | Force Russian |

Preference persists in SharedPreferences via `localeProvider`.

### Coverage

- Home, Config, Settings, Advanced settings, and shared widgets use `AppLocalizations`
- ~235 ARB keys in `app_en.arb` / `app_ru.arb`
- Helper strings for connection phase, uptime, panel sync, and split tunnel live in `l10n_helpers.dart`

See [localization.md](../localization.md).

## Profile management

Import, organize, and keep subscriptions fresh without leaving the app.

### Clipboard and QR import

**Config → Import** (or profile import sheet):

- **Clipboard** — paste `vless://`, `vmess://`, `trojan://`, and other supported share links; multi-link paste supported
- **QR scan** — camera scan on Android/iOS; desktop falls back to clipboard paste

Valid links flow through the existing censorship wizard when enabled. Invalid links show a non-blocking error.

### Subscription auto-refresh

Subscription profiles support:

- **Manual refresh** from the profile list
- **Auto-refresh interval** — Off, 6h, 12h, or 24h (default 6h)
- Refresh on app resume when stale
- Stale indicator in the UI

Refresh uses `SubscriptionHttpClient` with existing opt-in certificate pinning.

### Tags, favorites, and last used

- **Favorites** — star profiles; favorites sort first in lists and the Home quick-picker
- **Tags** — user-defined labels with chip display
- **Last used** — updated on successful connect for recency sorting

See [profiles.md](../profiles.md).

## Transparency

Open-source accountability: know what the app stores and what it logs.

### Privacy policy

- In-app: **Settings → Diagnostics → Privacy policy**
- Repository: [privacy.md](../privacy.md)
- Zero telemetry by design; local storage (profiles, settings) documented; RioNexGate panel upload described as opt-in only

### Log viewer

**Settings → Diagnostics → View logs**

| Feature | Detail |
|---------|--------|
| Default level | INFO and above |
| Debug | Opt-in via Settings; more verbose diagnostics |
| Credential scrubbing | Lines matching credential patterns are redacted before display |
| Export | Share/export without secrets |

Log files remain on device only; session SOCKS credentials are never written to logs.

## Work modes (Auto / Proxy / VPN)

Unified control over how RioNexTunnel routes traffic per platform.

**Settings → Work mode**

| Mode | Behavior |
|------|----------|
| **Auto** | Mobile → VPN (TUN); desktop → Proxy (system proxy + browser extension) |
| **VPN** | Full tunnel where supported (mobile); desktop shows warning if TUN unavailable |
| **Proxy** | Authenticated localhost inbounds + system proxy (desktop) |

Changing mode requires **reconnect**. Desktop Proxy mode documents kill-switch limitations vs mobile VPN.

See [work_modes.md](../work_modes.md).

## Windows browser helper & extension store

Desktop proxy auth without manual credential dialogs — now on Windows as well as Linux.

### Windows native messaging

- Native messaging host binary and registry manifests (Chrome, Edge, Firefox)
- `get_browser_helper_status` reports accurate install state
- Session credentials passed to the extension on connect; wiped on disconnect
- Host installed under user-local paths only (`%LOCALAPPDATA%`)

### Extension store preparation

Store assets and listings prepared under `extensions/secure-vpn-proxy-auth/store/`:

- Submission checklist
- EN/RU listing copy
- Store-ready icons in `manifest.json`

**Manual store submission** is required — no store secrets in the repository. Public store links will follow after review.

See [browser_extension.md](../browser_extension.md) and [windows_setup.md](../windows_setup.md).

## Security

Core invariants in v0.9.0 are **unchanged**:

| Principle | Implementation |
|-----------|----------------|
| Localhost only | SOCKS/HTTP on `127.0.0.1` — never `0.0.0.0` |
| Mandatory auth | Per-session password on every local proxy |
| No port 7890 | Unauthenticated SOCKS rejected in `validateSecure()` |
| Credential lifecycle | Wiped on disconnect; `active_config.json` removed |
| No secret logging | Log viewer redacts credentials; import/refresh never logs links at INFO |

New UI surfaces (profile picker, log viewer, import sheet) must not display config URLs, SOCKS passwords, or session secrets. Windows native messaging follows the same localhost-only, per-session credential model as Linux.

## Upgrade notes

P3 features are **additive and mostly opt-in**. No migration steps are required for existing users.

1. **Current users** — profiles, subscriptions, multihop, DNS, routing, and pinning work as in v0.8.0.
2. **Home flow** — use the profile quick-picker instead of the Profiles tab for everyday connects.
3. **Advanced settings** — P2 cards moved to **Settings → Advanced**; bookmarks may need updating.
4. **Language** — defaults to **System**; switch under **Settings → Appearance** if needed.
5. **Profile import** — optional; existing profiles are untouched.
6. **Auto-refresh** — off until you set an interval per subscription profile.
7. **Work mode** — **Auto** matches prior platform behavior; override only if you need Proxy or VPN explicitly.
8. **Windows** — install the browser extension and run browser-helper setup from Settings after upgrade.

## Known limitations

- **Localization follow-up** — secondary screens added during P3 agent merges may need additional ARB keys in a follow-up release.
- **Windows manual smoke test** — browser auth on Windows requires manual verification (Chromium + Firefox + extension); not fully automated in CI.
- **Extension store submission pending** — store package is ready; public Chrome Web Store / Firefox AMO links await manual publish and review.
- **QR on desktop** — camera QR scan is mobile-first; Linux/Windows/macOS use clipboard paste fallback.
- **Subscription refresh** — periodic refresh runs while the app is active; default interval ≥6h to limit battery use.
- **Desktop VPN override** — forcing VPN mode on desktop may be unsupported; the app shows a platform warning.
