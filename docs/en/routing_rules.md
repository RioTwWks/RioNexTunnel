# Custom routing rules

User-defined routing rules (domain, IP/CIDR, geosite, geoip) are prepended before subscription routing. Open **Settings → Censorship resistance → Custom routing rules**.

Presets: **RU direct / rest proxy**, **Blocked sites only**. Import/export JSON. Geo rules require `geoip.dat` / `geosite.dat` (fail closed on Xray).
