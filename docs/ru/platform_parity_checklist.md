Используйте после `scripts/fetch_cores.sh` (десктоп) или настройки нативного плагина (мобильные). На всех платформах **SOCKS только на `127.0.0.1` с паролем на сессию**.

## macOS browser helper paths

| Компонент | Путь |
|-----------|------|
| Native host | `~/Library/Application Support/V2rayBox/working/native_host/secure_vpn_native_host` |
| Chrome manifest | `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.secure.vpn.proxy_auth.json` |
| Firefox manifest | `~/Library/Application Support/Mozilla/NativeMessagingHosts/com.secure.vpn.proxy_auth.json` |

Полный чеклист: см. [английскую версию](../en/platform_parity_checklist.md).
