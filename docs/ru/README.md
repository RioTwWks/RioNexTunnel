## Статус платформ (MVP)

| Платформа | Режим | Статус |
|-----------|-------|--------|
| Linux | Proxy | Проверено — комбинации ядро × профиль |
| Android | VPN | Каркас + патчи форка; нужен тест на устройстве |
| iOS | VPN | Каркас + документация; нужен тест на устройстве |
| Windows | Proxy | Заглушка плагина; ядра через CMake install |
| macOS | Proxy | Паттерн XrayProcess в форке |

## Ключевые требования безопасности

- Локальные прокси только на `127.0.0.1` — никогда на `0.0.0.0`
- Случайный логин/пароль на каждую сессию; уничтожение при disconnect
- Учётные данные не логируются и не пишутся на диск
- Нет паттерна открытого порта `7890` без auth (класс уязвимостей марта 2026)
