# Мультихоп (Double VPN)

RioNexTunnel направляет трафик **через два и более VPN-сервера подряд**.

## Как пользоваться

1. Профиль **подписки** с минимум двумя серверами.
2. На **главном экране** выберите **входной сервер**.
3. Включите **Multihop (Double VPN)** и отметьте дополнительные hop.
4. Подключайтесь как обычно.

- **Xray-core** — цепочки через `proxySettings`.
- **sing-box** — цепочки через `detour`.

Локальный прокси на `127.0.0.1` не меняется — **дополнительные порты не открываются**.

## Задержка и анонимность

Мультихоп увеличивает задержку, но даёт прохождение через несколько узлов. Не используйте для повседневной скорости.

## Ограничения

- Только подписки.
- Минимум два разных сервера.
- WireGuard/SSH/Hysteria нельзя как промежуточный hop.

## Безопасность

- Учётные данные hop не логируются.
- Аутентификация SOCKS на `127.0.0.1` обязательна.
- Secure inbound injection не ослабляется.
