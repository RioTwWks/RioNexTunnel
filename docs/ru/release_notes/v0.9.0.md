# RioNexTunnel v0.9.0

<p align="right">
  <a href="../../en/release_notes/v0.9.0.md"><img src="https://img.shields.io/badge/lang-English-blue?style=for-the-badge" alt="English version"></a>

**P3 — UX, прозрачность и конкурентные преимущества.** В этом выпуске: упрощённое подключение, полная локализация RU/EN, расширенное управление профилями, инструменты прозрачности в приложении, единый выбор режима работы и browser helper для Windows на уровне Linux. Новое поведение **опционально** или добавочное; инварианты безопасного SOCKS и connect по умолчанию не меняются.

---

## Главное

- **Минималистичный UI** — подключение с главного экрана за ≤2 нажатия; компактные настройки и отдельный экран Advanced для функций P2 ([#79](https://github.com/RioTwWks/RioNexTunnel/pull/79)).
- **Полная локализация (RU/EN)** — `flutter gen-l10n`, ~235 ключей ARB, системная локаль и выбор языка в приложении ([#83](https://github.com/RioTwWks/RioNexTunnel/pull/83)).
- **Управление профилями** — импорт из буфера/QR, автообновление подписок, теги и избранное ([#81](https://github.com/RioTwWks/RioNexTunnel/pull/81)).
- **Прозрачность** — политика конфиденциальности, просмотр логов без credentials, режим работы Auto/Proxy/VPN ([#80](https://github.com/RioTwWks/RioNexTunnel/pull/80)).
- **Browser helper для Windows** — native messaging на уровне Linux; пакет для публикации расширения в store ([#82](https://github.com/RioTwWks/RioNexTunnel/pull/82)).
- **План распределения P3** — документация по агентам и координации ([#78](https://github.com/RioTwWks/RioNexTunnel/pull/78), [#84](https://github.com/RioTwWks/RioNexTunnel/pull/84)).

## Минималистичный UI

Более чистый главный экран и настройки без потери функций P2.

### Подключение за ≤2 нажатия

1. На **главном экране** нажмите **быстрый выбор профиля** (только имя и тип — без ссылок на конфиг и секретов).
2. Нажмите **Подключить**.

Если профиль уже выбран — **одно нажатие**. Избранные профили отображаются первыми в списке.

### Компактные настройки

В **Настройках** остаются основное: внешний вид (тема + язык), ядро, режим работы, диагностика и панель RioNexGate. Kill switch, DNS, маршрутизация, цензуроустойчивость, pinning сертификата и split tunneling перенесены в **Advanced**.

### Экран Advanced settings

**Настройки → Advanced** — отдельный экран со всеми карточками P2 без изменения логики:

- Kill switch
- Расширенный DNS (мобильный TUN)
- Пользовательские правила маршрутизации
- Цензуроустойчивость
- Certificate pinning подписки
- Split tunneling (Android VPN)

Тема по умолчанию — **системная** (`ThemeMode.system`).

## Полная локализация (RU/EN)

Основной интерфейс полностью локализован через `flutter gen-l10n`.

### Выбор языка

**Настройки → Внешний вид → Язык**

| Вариант | Поведение |
|---------|-----------|
| **Системный** | Следовать локали ОС (RU или EN при поддержке) |
| **English** | Принудительно английский |
| **Русский** | Принудительно русский |

Предпочтение сохраняется в SharedPreferences через `localeProvider`.

### Охват

- Главный экран, Config, Настройки, Advanced и общие виджеты используют `AppLocalizations`
- ~235 ключей ARB в `app_en.arb` / `app_ru.arb`
- Вспомогательные строки (фаза подключения, uptime, синхронизация панели, split tunnel) — в `l10n_helpers.dart`

См. [localization.md](../localization.md).

## Управление профилями

Импорт, организация и актуальность подписок без выхода из приложения.

### Импорт из буфера и QR

**Config → Импорт** (или лист импорта профиля):

- **Буфер обмена** — вставка `vless://`, `vmess://`, `trojan://` и других поддерживаемых ссылок; поддерживается вставка нескольких ссылок
- **QR-скан** — камера на Android/iOS; на десктопе — fallback на вставку из буфера

Валидные ссылки проходят через существующий мастер цензуроустойчивости при включении. Невалидные ссылки показывают некритичную ошибку.

### Автообновление подписки

Для профилей подписки:

- **Ручное обновление** из списка профилей
- **Интервал автообновления** — Выкл., 6 ч, 12 ч или 24 ч (по умолчанию 6 ч)
- Обновление при возобновлении приложения, если данные устарели
- Индикатор устаревания в UI

Обновление использует `SubscriptionHttpClient` с существующим опциональным certificate pinning.

### Теги, избранное и «недавно использованные»

- **Избранное** — звёздочка у профиля; избранные первыми в списках и на главном экране
- **Теги** — пользовательские метки с чипами
- **Последнее использование** — обновляется при успешном connect для сортировки по давности

См. [profiles.md](../profiles.md).

## Прозрачность

Подотчётность open-source: что хранится и что попадает в логи.

### Политика конфиденциальности

- В приложении: **Настройки → Диагностика → Политика конфиденциальности**
- В репозитории: [privacy.md](../privacy.md)
- Нулевая телеметрия по дизайну; локальное хранение (профили, настройки) документировано; загрузка в панель RioNexGate — только по согласию

### Просмотр логов

**Настройки → Диагностика → Просмотр логов**

| Функция | Детали |
|---------|--------|
| Уровень по умолчанию | INFO и выше |
| Debug | Включается в настройках; более подробная диагностика |
| Скрытие credentials | Строки с признаками учётных данных редактируются перед показом |
| Экспорт | Поделиться/экспорт без секретов |

Файлы логов только на устройстве; session SOCKS credentials в логи не записываются.

## Режимы работы (Auto / Proxy / VPN)

Единый контроль маршрутизации трафика по платформам.

**Настройки → Режим работы**

| Режим | Поведение |
|-------|-----------|
| **Auto** | Мобильные → VPN (TUN); десктоп → Proxy (системный прокси + расширение браузера) |
| **VPN** | Полный туннель где поддерживается (мобильные); на десктопе — предупреждение если TUN недоступен |
| **Proxy** | Аутентифицированные localhost inbounds + системный прокси (десктоп) |

Смена режима требует **переподключения**. Режим Proxy на десктопе документирует ограничения kill switch относительно мобильного VPN.

См. [work_modes.md](../work_modes.md).

## Browser helper для Windows и публикация расширения

Авторизация прокси на десктопе без ручного ввода credentials — теперь и на Windows, как на Linux.

### Native messaging в Windows

- Бинарник native messaging host и манифесты в реестре (Chrome, Edge, Firefox)
- `get_browser_helper_status` отражает реальное состояние установки
- Session credentials передаются расширению при connect; стираются при disconnect
- Host только в пользовательских путях (`%LOCALAPPDATA%`)

### Подготовка к store

Материалы для публикации в `extensions/secure-vpn-proxy-auth/store/`:

- Чеклист submission
- Тексты листинга EN/RU
- Иконки для store в `manifest.json`

**Ручная публикация** в store обязательна — секреты store не хранятся в репозитории. Публичные ссылки появятся после модерации.

См. [browser_extension.md](../browser_extension.md) и [windows_setup.md](../windows_setup.md).

## Безопасность

Базовые инварианты v0.9.0 **не изменились**:

| Принцип | Реализация |
|---------|------------|
| Только localhost | SOCKS/HTTP на `127.0.0.1` — никогда `0.0.0.0` |
| Обязательная auth | Пароль на сессию на каждом локальном прокси |
| Нет порта 7890 | Неаутентифицированный SOCKS отклоняется в `validateSecure()` |
| Жизненный цикл credentials | Стираются при disconnect; удаляется `active_config.json` |
| Без логирования секретов | Просмотр логов редактирует credentials; импорт/обновление не логирует ссылки на уровне INFO |

Новые UI-элементы (выбор профиля, просмотр логов, импорт) не показывают URL конфигов, пароли SOCKS и session secrets. Windows native messaging следует той же модели localhost-only и credentials на сессию, что и Linux.

## Обновление

Функции P3 **добавочные и в основном опциональные**. Миграция для текущих пользователей не требуется.

1. **Текущие пользователи** — профили, подписки, мультихоп, DNS, маршрутизация и pinning работают как в v0.8.0.
2. **Главный экран** — используйте быстрый выбор профиля вместо вкладки Profiles для повседневного connect.
3. **Advanced settings** — карточки P2 перенесены в **Настройки → Advanced**; закладки могут потребовать обновления.
4. **Язык** — по умолчанию **Системный**; смените в **Настройки → Внешний вид** при необходимости.
5. **Импорт профилей** — опционален; существующие профили не затрагиваются.
6. **Автообновление** — выключено, пока не задан интервал для профиля подписки.
7. **Режим работы** — **Auto** соответствует прежнему поведению платформы; переопределяйте только при явной необходимости Proxy или VPN.
8. **Windows** — установите расширение браузера и выполните настройку browser helper в Настройках после обновления.

## Известные ограничения

- **Доработка локализации** — вторичные экраны, добавленные при merge агентов P3, могут потребовать дополнительных ключей ARB в следующем релизе.
- **Ручной smoke-тест Windows** — авторизация в браузере на Windows требует ручной проверки (Chromium + Firefox + расширение); в CI не автоматизирована полностью.
- **Публикация в store ожидается** — пакет готов; публичные ссылки Chrome Web Store / Firefox AMO — после ручной публикации и модерации.
- **QR на десктопе** — сканирование камерой в приоритете на мобильных; Linux/Windows/macOS используют вставку из буфера.
- **Обновление подписок** — периодическое обновление работает при активном приложении; интервал по умолчанию ≥6 ч для экономии батареи.
- **Принудительный VPN на десктопе** — может быть не поддержан; приложение показывает предупреждение платформы.
