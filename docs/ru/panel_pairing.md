# Сопряжение с панелью RioNexGate

RioNexTunnel может опционально сопрягаться с панелью [RioNexGate](https://github.com/RioTwWks/RioNexGate) для управляемых подписок, статистики трафика и удалённых команд.

## Добавочная интеграция

Функции панели **включаются по желанию**. Если URL панели не настроен, приложение работает как обычный VPN-клиент.

- Ручные профили (`vless://`, URL подписок и т.д.) работают без изменений.
- После успешного сопряжения добавляется профиль **RioNexGate**.
- **Сброс сопряжения** удаляет только профиль RioNexGate и учётные данные панели — остальные профили сохраняются.

## Шаги сопряжения

1. Откройте **Настройки → Панель RioNexGate**.
2. Включите раздел панели и укажите базовый URL (например, `https://panel.example.com`).
3. Вставьте **токен сопряжения** из админки панели и нажмите **Зарегистрировать**.
4. Клиент сохраняет **токен устройства** в защищённом хранилище и создаёт/обновляет профиль RioNexGate.

## Автоматическая синхронизация

| Функция | Поведение |
|---------|-----------|
| Синхронизация конфига | По умолчанию каждые **15 минут** (настраивается: 15 / 30 / 60 / 120 мин). Пропуск перезаписи при неизменном `config_hash`. |
| Отправка статистики | Каждые **60 секунд** при подключении и финальная отправка при отключении. |
| Офлайн | Последний рабочий конфиг кэшируется; статистика ставится в очередь и отправляется при восстановлении связи. |

## Поведение при подключении

Если панель отдаёт полный JSON-объект `config`, RioNexTunnel использует кэшированный/синхронизированный JSON для профиля **RioNexGate** (вместо повторной загрузки URL подписки). При отсутствии кэша — стандартный пайплайн подписки.

## Безопасность

- **Токен устройства** — только для API панели, отдельно от транспортных/VLESS-учётных данных.
- Токены хранятся в **flutter_secure_storage**, не в SharedPreferences.
- SOCKS5 на `127.0.0.1` по-прежнему требует аутентификацию — без открытых локальных прокси.

## Сброс сопряжения

Кнопка **Очистить** в настройках удаляет:

- Токен устройства (защищённое хранилище)
- Кэш конфига панели и очередь статистики
- Профиль RioNexGate

Ручные профили **не** удаляются.
