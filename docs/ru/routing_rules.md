# Пользовательские правила маршрутизации

Правила (домен, IP/CIDR, geosite, geoip) добавляются **перед** маршрутизацией подписки. **Настройки → Цензуроустойчивость → Пользовательские правила**.

Пресеты: **RU direct / rest proxy**, **Blocked sites only**. Импорт/экспорт JSON. Geo-файлы обязательны (fail closed на Xray).
